### LOW severity
- **Field-symmetry gap is documentation-only, not a defect (noting for the record).**
  The dispatch asked me to "flag any field named in ch6 but missing from the
  template, or vice-versa." Direction one (ch6 → template): every field ch6 names
  for a record — `claim`, `kind`, `tags`, `fix`, `scope`, `evidence`, `confidence`
  (`docs/06-learning-across-projects.md:60`) and the 5 kinds gotcha/prerequisite/
  pivot/pattern/anti-pattern (`:49`–`:52`) — is present in the template
  (`templates/LEARNINGS.md.template:19`, `:21`–`:35`). Direction two (template →
  ch6): the template carries two fields ch6's prose never names as record fields —
  `id` (`:22`) and `strength` (`:31`). This is **not** a contradiction: D20 also
  omits them from its inline field list (`.gotm/DECISIONS.md:297`), but the audit
  dispatch itself sanctions `strength` ("+ optional `strength`"), the sibling
  producer prompt emits both (`prompts/outcome-analysis.md`, schema block: `id`,
  …, `strength`), and ch6 discusses the *concept* of within-project recurrence
  weight at `:72` ("on the strength of its own project") and per-record ids
  implicitly via the `L#` index scheme. So the two halves shipped under D20 (chapter +
  template) are mutually consistent in substance; the gap is only that ch6's
  one-paragraph record sketch (`:60`) elides `id`/`strength` for readability. If
  desired, a one-clause addition to `:60` ("…a `confidence` — plus a stable `id`
  and an optional within-project `strength`") would make the chapter's field list
  literally exhaustive. Cosmetic; fix if convenient.

- **Index tag-separator differs from the YAML tag separator (intentional, but a
  reader could trip).** The generated-Index format uses a middle-dot inside the
  bracket — `[<tag>·<tag>]` (`:11`) — while the YAML source uses a comma-separated
  list — `tags: [<tech>, <domain>, <phase>]` (`:25`). These are two surface
  renderings of the same field (Index is an explicitly *generated projection*, not
  a literal copy of the record), so this is internally coherent and not a bug. A
  half-line note ("Index renders tags dot-joined") would remove the only spot where
  a first-time reader might think the two disagree. Cosmetic.
